## 关于我 / About me

你好，我是 Jackson Lewis。我关注统计方法、数学建模与数据可视化，也喜欢把分析过程中反复遇到的问题做成可以直接使用的工具。

目前，我在开发 **StatM**：一款面向统计学习与科研数据分析的 Windows 桌面应用。希望让数据整理、统计计算、图表制作和结果回顾能够在一个工作空间里完成，减少环境配置和工具切换的负担。

我看重模型能否解释问题、结果能否复现，以及图表能否清楚地传达证据。

*I work on statistical analysis, mathematical modeling, and scientific visualization. My current project is StatM, an offline desktop application that brings data preparation, analysis, and figure export into one workspace.*

## 关注方向 / Interests

- **统计分析**：理解方法的适用条件，结合数据与研究问题解释结果。

## 代表项目 / Featured project

### 📊 [StatM](https://github.com/Lewis-18/StatM)

**让数据，抵达洞见。**

StatM 是我开发的 Windows 桌面统计分析与科学可视化应用，核心功能可以离线使用，无需另行配置 Python 或 Node.js。

| 工作环节 | 可以做什么 |
| --- | --- |
| 数据准备 | 导入 CSV、TXT 和 Excel，预览字段、处理缺失值与重复记录。 |
| 统计分析 | 描述统计、相关分析、假设检验、线性回归和主成分分析。 |
| 图表探索 | 二维与三维图表、散点与记录联动、独立图表背景。 |
| 结果整理 | 分析历史与兼容记录对照、图表和统计表导出、Python/R 分析脚本导出。 |

二维图表支持 PNG、SVG 和 PDF；三维图表支持当前视角 PNG 和 PDF。
